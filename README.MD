# Банковское Приложение
Это приложение предоставляет функции для работы с банковскими транзакциями, конвертацией валют, анализом расходов, а также создания отчетов по категориям и вычисления сбережений для инвестиционной копилки. Приложение использует данные из Excel-файлов и предоставляет пользователю функциональность через консольный интерфейс.

## Функциональность
### Основные функции:
1. Главная страница:

Выводит приветствие в зависимости от времени суток.
Отображает анализ по картам, включая последние 4 цифры карты, общую сумму расходов и кэшбэк.

2. Сервис Инвесткопилка:

Рассчитывает сумму, которую можно отложить в "Инвесткопилку" по заданному лимиту.
Вычисляет округленные суммы транзакций и находит возможные сбережения.

3. Отчет траты по категории:

Формирует отчет по расходам по категориям за последние 3 месяца.
Позволяет вводить дату для формирования отчета на основе данных из Excel-файла.
